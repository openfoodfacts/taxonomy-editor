# Entry descriptions and comments

An entry's English description and editing notes appear above its translations,
between the parent/child lists and synonyms. Read these notes before editing an
entry: they can explain its meaning or which children belong in the category.

The context displays nonempty `description:en`, `comment:en`, and `comments:en`
properties. These remain ordinary taxonomy properties. Use **Edit in properties**
to jump to the existing Properties table, then edit the appropriate value and
save your changes. Updating or removing a property also updates the context.

Imported entries show their context without the edit link, preserving their
existing read-only property behavior. Entries without these properties have no
context section.
